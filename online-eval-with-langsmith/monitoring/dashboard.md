# Dashboard

***

## Dashboard Name

`Customer Doubt Solver RAG - Online Evaluation`

The dashboard was created in LangSmith to monitor operational, safety,
and quality performance of the RAG application in one place.

***

## Dashboard Metrics

### Operational
- P95 Latency
- P99 Latency
- Average Cost
- P95 Cost

### Safety
- Toxicity

### Quality
- Contextual Relevancy
- Faithfulness
- Answer Relevancy

Detailed values and observations for each metric are documented in
[metrics/operational-metrics.md](metrics/operational-metrics.md),
[metrics/safety-metrics.md](metrics/safety-metrics.md), and
[metrics/quality-metrics.md](metrics/quality-metrics.md).
